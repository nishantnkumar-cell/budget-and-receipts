# Manual editing and split approval

OCR and AI output must remain a draft. The user can edit merchant, date, receipt totals, subtotal, VAT, item descriptions, item amounts and categories. Items can be added or deleted.

Save Draft Only never changes spending reports. Approval is enabled only after the user confirms review and the proposed split total matches the absolute bank transaction amount within one penny. A final confirmation dialog commits the splits and records the approval in change history.
